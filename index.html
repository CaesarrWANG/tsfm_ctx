效应语言 · 两阶段方法

在文本和预测之间放一层可检查的“效应语言”：9B 语言模型把文本解析成效应，确定性编译器把效应变成逐步约束和协变量，并带有可证明的安全保证；微调后的 Chronos-2 在这些条件下做预测。第二阶段的训练不需要成对的文本–序列数据。

00 / 概览

一句话概括

模型负责“指出”，代码负责“计算”：语言模型只照抄原文中的时间和数值，并判断效应类型；换算、约束执行、安全投影都由确定性程序完成；时序模型负责补全文本没说清的部分，例如只给了方向时的幅度、外部输入与目标之间的关系。

学习的模型确定性程序
IN
背景文本或结构化效应（GIFT-Eval-CTX）
01
文本解析Qwen3.5-9B + LoRA，输出效应行，原文片段照抄
02

03

OUT
预测 + 说明25 个样本；自动生成可溯源的预测说明

贡献 1 · 效应语言与安全保证

文本和结构化信息编译到同一种带形式语义的中间表示；陈述为真时截断不会让预测变差，为假时损失有界。

贡献 2 · 不需要成对数据的训练

从真实序列的未来中提取效应，加入“说了但没发生”的陈述、不同精度的描述和外部输入，自监督地训练以效应为条件的预测模型。

贡献 3 · 小模型、可溯源

9B + 0.12B 在两个基准上超过 TimeBraid 和基于 GPT-5.6 的智能体；每个效应都能追溯到原文句子。

01 / 背景

任务与基准

给定一段序列的历史，以及与之相关的背景信息，预测未来 H 步。点预测和概率预测都要评价。背景信息可能是结构化的效应描述，也可能是自然语言。

GIFT-Eval-CTX 结构化效应

  • 10,000 道题，78 个“数据集 × 预测长度”组；短、中、长期，最长 900 步
  • 背景信息：Macro（趋势、全程水平范围、季节性）与 Micro（局部偏移、跳变）
  • 指标：相对季节性朴素预测的 MASE，按组取几何平均
  • 检验：能否把效应信息用好（第二阶段）

Context-is-Key 自然语言

  • 355 道题，71 类任务；一般预测 24–100 步
  • 背景信息：事件、约束、因果关系、外部输入、历史异常等的文本描述
  • 指标：官方 RCRPS，即概率预测误差，重点区域加权，违反约束会被重罚
  • 检验：能否读懂文本并用好（完整链路）

现有路线

路线代表局限
时序基础模型，只看历史Chronos-2、TimesFM、Moirai用不上文本
大模型直接给出预测GPT、Gemini、Llama 直接提示依赖前沿大模型；数值由模型生成，过程不可检查
端到端融合文本和序列TimeBraid（1.2B–6.7B）需要大规模成对数据；在两个基准上都接近纯历史预测的水平
智能体调用工具MoiraiAgent（GPT-5.6）依赖前沿大模型，成本高
02 / 动机

从观察到设计

每一项设计都对应一个具体的观察。

观察由此得到的设计
文本里对预测有用的，大多是可以精确表达的“效应”：某段时间等于多少、不超过多少、上升还是下降、外部输入怎么变定义一种效应语言作为文本和预测之间的中间表示
大模型读文本没问题，但直接输出时，时间换算对的只有 55%（9B）到 75%（27B）语言模型只指出原文片段，换算交给确定性的编译器
读错的效应会损害预测约束执行要有可证明的安全性：陈述为真时不变差，为假时损失有界
文本给的信息常常不完整：只有方向、只有极值、只有形状、只有外部输入训练一个以效应为条件的时序模型，从历史中补全
成对的“文本–序列”数据稀缺从序列的真实未来中自动提取效应，自监督地训练第二阶段
03 / 方法

效应语言 + 两阶段

文本前端（Context-is-Key）和结构化前端（GIFT-Eval-CTX）都编译到同一种效应语言，之后的编译、预测、投影完全共用。

3.1

效应语言

效应例子语义（编译结果）执行
精确值 / 倍数 / 增减 / 百分比“平时的 4 倍”“降为零”某几步等于 v硬约束
范围、上限、下限“不超过 6.29”某几步落在 [a, b]硬约束
全程水平范围Macro 的水平范围所有步落在 [a, b]硬约束
仅方向“节假日车流会减少”某几步高于或低于平时模型推断幅度
趋势、季节幅度、反复偏移、季节性Macro 的趋势和季节性形状模板模型
外部输入时间表“负载 0.2，从 05:48:01 到 05:48:27”；参考序列；“10 点转晴”历史加未来的逐步输入序列模型学习关系
历史屏蔽“每 15 天维护 7 天，未来不再维护”历史中的异常时段标为缺失程序

每条效应带有可信度（已确认 / 传闻）。传闻只作为提示交给模型，不作为硬约束执行。

3.2

第一阶段：文本 → 效应语言

模型与输出

  • Qwen3.5-9B + LoRA 适配器；原模型权重不变，对话能力保留
  • 每条陈述一行；时间和数值照抄原文，不自己计算
  • 照抄的片段必须能在原文中找到，否则丢弃；换算成第几步、多少数值，由代码完成

训练数据（约 8 万条，不含测试文本）

  • 模板文本，以及 27B 改写的自然文本
  • CAF-7M 训练集的真实文本：27B 标注，经“换算回去与标注一致”核对后保留
  • 外部输入、参考序列、状态变化、历史屏蔽的合成段落

输出示例

  from 2013-05-28 12:00:00 for 2 hours | 4 |

3.3

效应编译与安全投影

预测之后，对已确认的约束做逐步截断：区间约束对每个样本截断，精确值把分布的中位数平移到该值、离散程度不变。设某一步的预测分布为 F，真实值为 y，约束区间为 C = [a, b]。

定理 1 · 真约束不变差

y ∈ C ⇒ CRPS(F′, y) ≤ CRPS(F, y)点预测：|clip(x) − y| ≤ |x − y|

截断只把区间外的累积分布压到 0 或提到 1，而真实值不在那里，所以被积函数逐点不增。

定理 2 · 假约束损失有界

y ∉ C, d = dist(y, C) ⇒ CRPS(F′, y) ≤ CRPS(F, y) + d点预测：误差 ≤ max(原误差, d)

只有 y 与区间之间长度为 d 的一段会变差，每点最多增加 1。

命题 3 · 精确值平移

δ = |v − y| ⇒ CRPS(F′, y) ≤ CRPS(F, y) + 2δ陈述准确（δ = 0）时不增加

中位数使 E|X − c| 最小，再用两次三角不等式即可。

含义：代码层是可证明的“安全层”，损失只可能来自读错，或者文本本身不准确。端到端模型和大模型直接提示都没有这种保证。

3.4

第二阶段：以效应为条件的预测

模型

  • Chronos-2 全量微调（约 1.2 亿参数）
  • 11 条效应通道 + 1 条外部输入通道，作为已知的未来协变量输入
  • 通道：下界、上界、方向、可信度、全程上下界、趋势模板、季节幅度、反复偏移方向和水平、季节性、外部输入

训练流程（定稿版本 E16）

  • 短窗口（24–48 步）8,000 步
  • + 长窗口（480 / 720 步）与短窗口回放，8,000 步
  • + 外部输入，3,000 步

自监督训练数据（不需要任何文本）

  • GIFT-Eval 预训练集的真实窗口，不含测试数据
  • 用规则从真实未来中提取效应：一半按结构化格式描述，一半按文本格式描述
  • 描述分三档精度：精确值、大致幅度、仅方向
  • 写入大幅度效应；加入“说了但没发生”的陈述和可信度标签
  • 约 30% 的窗口加入由人造外部输入驱动的成分：比例、平方、带延迟的关系，以及与目标无关的输入
3.5

推理与可溯源说明

混合方案

  • 有陈述的步：第二阶段模型，再做安全投影
  • 没有陈述的步、精确值的步：以原版 Chronos-2 的预测为基础
  • 没有读出任何效应：原版 Chronos-2 只看历史的预测

说明由代码根据效应行和预测结果自动生成，不让语言模型自由发挥，每一句都能追溯到原文和计算过程。

05 / 局限与下一步

还需要解决的问题

以下几点在投稿前需要补上实验或在论文中如实说明。

“看过测试题”

第一阶段的若干修正和外部输入的训练模板，是看过 Context-is-Key 的题型后设计的；第二阶段版本也是按测试成绩选的。需要一个独立的文本测试集来检验。

适用范围

常识和类比类的题（约占 Context-is-Key 权重的 14%）不在方法范围内，例如“新区靠近河流，参照其他区估计救援次数”。前沿大模型的优势主要在这里。

第二阶段在文本基准上的贡献偏小

Context-is-Key 上约 0.01，比 GIFT-Eval-CTX 上（0.634 → 0.476）小得多：文本中的效应多数带明确数值，代码直接写入就够了。
